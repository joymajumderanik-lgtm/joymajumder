# joymajumder



description 

<p>Ai voise assistant...This project is a simple voice-controlled personal assistant made with Python. It listens to your voice, understands what you say, and speaks back to you. The assistant can tell you the current time and date, open websites like YouTube or Google, search anything on Google, and read short information from Wikipedia. It uses speech recognition to hear your voice and a text-to-speech engine to give spoken replies. When the program starts, it keeps listening in a loop and waits for your next command until you say stop or exit. The whole system works by converting speech into text, checking what command you gave, and then performing the correct action. This project is useful because it shows how voice control, automation, and online information can be combined in one simple program. It is easy to use, easy to understand, and can be improved later with more features like weather updates, music control, reminders, or a wake-up word such as “Hey Anik.”</p>
